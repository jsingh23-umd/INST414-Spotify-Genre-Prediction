# INST414-Spotify-Genre-Prediction
Predicting music genres using Spotify audio features and supervised learning


Spotify Genre Prediction

I used supervised learning to predict music genres based on Spotify audio features.

Dataset: 
I used the Spotify Tracks Dataset from Kaggle. I selected five genres: pop, rock, hip-hop, jazz, and classical. After removing duplicates, I had 4,794 songs.

Method:
I used Python and scikit-learn to train a Decision Tree Classifier. I split the data into 80% training and 20% testing.

Results:
Training accuracy: 66.49%
Testing accuracy: 64.55%
Most important feature: Acousticness
